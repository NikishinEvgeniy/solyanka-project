# Солянка — Frontend

Главная страница кулинарного сервиса «Солянка». Она знакомит пользователя с проектом, даёт доступ к разделам
рецептов, профилю и избранному. Доступ к приложению защищён Keycloak: при отсутствии активной сессии провайдер
перенаправляет пользователя на форму входа до показа главной страницы.

## Стек
React, TypeScript, Vite

## Запуск
1. `npm install`
2. `npm run dev`

Для локального входа должен быть доступен realm `solyanka` в Keycloak.

Тестовая учётная запись из локального realm: логин `test`, пароль `test`. Она предназначена только для
командной разработки; email `test@test` уже отмечен как подтверждённый, обязательных действий при входе нет.

## Скрипты
- `npm run dev` — запуск в режиме разработки;
- `npm run build` — проверка TypeScript и production-сборка;
- `npm run lint` — статический анализ;
- `npm test` — компонентные тесты главной страницы и состояния авторизации.

## Структура
- `src/components` — шапка и подвал;
- `src/pages` — страницы приложения;
- `src/assets/images` — логотип, яблоки и плиточный фон;
- `src/assets/fonts` — декоративный шрифт Valisca;
- `src/feature/login` — настройка Keycloak;
- `src/library/keycloak` — отдельная тема формы входа.

## Главная страница

Страница повторяет desktop-макет 1440 × 1080 и адаптируется для узких экранов. Навигация содержит ссылки на
все рецепты, рецепты пользователя, избранное и профиль. Кнопка «Выйти» завершает Keycloak-сессию. Сердце
избранного окрашивается и делает оборот при наведении; при системной настройке `prefers-reduced-motion` анимации
отключаются.

Типографика макета: Valisca 96 px для декоративного заголовка, Brygada 1918 50 px для слогана и 24 px для основного текста,
Piazzolla Bold 20 px для навигации и Piazzolla Light 14 px для подвала. Все шрифты включаются в production-сборку
и не требуют обращения к внешнему CDN.
